# RE:ROUTINE

循環型のホームケア製品を題材に、回収・再利用の仕組みと想定効果を図解で伝えるポートフォリオ作品です。ブランド、サービス、数値は架空の設定で、商品の販売・申込は行っていません。

静的なHTML・CSS・JavaScript・SVGで制作しています。[GitHub Pagesで公開中](https://oreo-k-lab.github.io/reroutine-impact-site/)です。

## ローカルで確認

Node.jsで`node serve.mjs`を実行し、`http://127.0.0.1:4173/`を開いてください。依存パッケージのインストールやビルドは不要です。SVGへのデータ反映を含む表示確認には、`index.html`の直接表示ではなくローカルサーバーを使用します。

## ファイル構成

| パス | 役割 |
|---|---|
| `index.html` | ページ本文・図解のHTML代替・架空案件の注記 |
| `styles.css` | レイアウト、レスポンシブ表示、動きの低減設定 |
| `script.js` | 循環ライン、表示アニメーション、操作、データ反映 |
| `site-data.js` | KPI、年度目標、比較条件、注記の編集元 |
| `assets/` | 現行ページで使用する画像・SVG 11点 |
| `serve.mjs` | ローカルプレビュー専用のサーバー |

## デザインと操作

循環フロー・比較・年度目標にはSVG図解を使用します。1280px以上ではSVG、1279px以下では同じ内容のHTML版を表示します。SVG表示時も詳細を伝えるHTML版を読み上げ用に残し、ページ先頭にはキーボードで使える「本文へ移動」を設けています。

ProblemからImpactへ続く循環ライン、ProblemとBenefitsの間で流れる文字、各セクションの短い登場演出を実装しています。「動きを止める」ボタン、またはOSの「動きを減らす」設定を使用すると、動きを省いて内容を静的に表示します。ヘッダーのリンク、商品CTA、FAQはサイト内で完結し、外部の購入先や申込先はありません。

## 数値を編集する場所

KPI、年度目標、比較条件、注記は`site-data.js`で一元管理しています。回収率や目標比などの派生値は計算され、HTMLとSVGの`data-field`へ反映されます。表示値を個別に書き換えず、元データを編集してください。掲載値はすべて架空の想定値です。

## 公開時の扱い

- `index.html`には`noindex, nofollow`を設定しています。公開後も検索結果への掲載を目的とせず、ポートフォリオからリンクして見せる方針です。
- 写真・挿絵・図解の制作にAIを使用しています。採用写真の生成・編集記録では外部サイトの画像を入力していませんが、第三者の権利を侵害しないことまで保証するものではありません。
- ページ表示に必要なのはHTML、CSS、JavaScript 2点、`assets/`の11点です。`serve.mjs`はローカル確認用で、ページからは読み込みません。
- ローカルでは全ページのレスポンシブ表示・画像・操作・動きの低減設定を確認済みです。公開URLでは1280／390／320pxで横はみ出しなし、画像6点の読み込み、ページ内リンクの参照先、FAQ・モバイルメニュー・文字帯の停止／再開、`noindex, nofollow`、コンソールエラーなしを確認しました。公開URLでOSの「動きを減らす」をオンにした実画面確認は別途必要です。
